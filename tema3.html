3. Modelo AR: «hoy se parece a ayer»

Idea simple

Un AR(1) dice: el valor de hoy es una fracción φ del de ayer más una sorpresa nueva. Si φ = 0,9 la serie tiene mucha memoria y se mueve lento. Si φ = 0,1 olvida casi todo de un día para otro. Si φ es negativo, la serie zigzaguea: un día alto, otro bajo.

AR(1): mueve φ
Serie (línea azul) y predicción a 12 pasos (naranja)
ACF teórica: ρ(k) = φk

  • La ACF baja geométricamente: con φ alto cae despacio; con φ negativo alterna de signo.
  • La predicción parte del último dato y se acerca a la media (cero aquí) cada vez más: la memoria se va perdiendo.
  • Con φ cerca de ±1 la serie casi deja de ser estacionaria: nunca vuelve a su media.
Versión formal
AR(1): Yt = c + φ Yt−1 + εt ,   εt ~ ruido blanco(0, σ²)
μ = c/(1−φ)    Var(Yt) = σ2/(1−φ2)    ρk = φk

Es si |φ| < 1. Predicción a h pasos:

ŶT+h|T = μ + φh(YT − μ)

El AR(p) añade más retardos: Y_t = c + φ_1 Y_{t-1} + … + φ_p Y_{t-p} + ε_t. Para AR(2) las condiciones son φ_1+φ_2 < 1, φ_2−φ_1 < 1 y |φ_2| < 1. Rasgo para identificarlo: la PACF se corta tras el retardo p, mientras la ACF decae.

Ejemplo del tema

La inflación de EE. UU. se modela con un AR(2): la inflación de hoy depende de las de los dos periodos anteriores, y la predicción vuelve despacio hacia el nivel medio.

4. Modelo MA: «hoy arrastra las sorpresas recientes»

Idea simple

Un MA(1) dice: el valor de hoy es la sorpresa de hoy más una parte θ de la sorpresa de ayer. El eco dura justo un periodo y desaparece. Ejemplo: una huelga sorpresa de transporte afecta a las ventas de hoy y, en parte, a las de mañana; pasado mañana ya no se nota.

MA(1): mueve θ
Serie
ACF teórica: solo el retardo 1 es distinto de 0

Versión formal
MA(1): Yt = μ + εt + θ εt−1
Var(Yt) = σ2(1+θ2)    ρ1 = θ/(1+θ2)    ρk = 0 si k ≥ 2

Un MA siempre es estacionario. La condición de es |θ| < 1. Rasgo para identificarlo: la ACF se corta tras el retardo q y la PACF decae. Predicción: a un paso usa el último shock, Ŷ_{T+1|T} = μ + θ ε_T; a dos o más pasos, el modelo ya no tiene información y predice la media μ.

5. ARMA y cómo elegir p y q

Idea simple

Un combina memoria de los valores pasados (parte AR) con eco de las sorpresas pasadas (parte MA). Sirve cuando ni un AR ni un MA solos encajan con pocos parámetros.

Versión formal
ARMA(1,1): Yt = c + φ Yt−1 + εt + θ εt−1

Se necesita φ ≠ −θ: si fueran iguales, los dos efectos se cancelarían y la serie sería ruido blanco.

6. ARIMA: cuando hay tendencia

Idea simple

Un ARMA solo funciona con series estables. Si la serie tiene tendencia, primero se «estabiliza» restando cada dato al anterior (se ) y después se modela el resultado con un ARMA. La «I» de ARIMA es de integrada: deshacer la diferencia es sumar (integrar).

El número de veces que diferencias es d. En la práctica d vale 0, 1 o, rara vez, 2, y se decide con el test .

Versión formal
(1 − φ1 L − … − φp Lp)(1−L)d Yt = c + (1 + θ1 L + … + θq Lq) εt

Con el operador retardo, (1−L)^d son las d diferencias, la parte izquierda es el AR y el paréntesis de la derecha es el MA. ARIMA(1,0,0) es un AR(1); ARIMA(0,1,0) es un paseo aleatorio.

Ejemplo del notebook

Con el PIB de España se ajusta un ARIMA y se predicen 5 periodos. Después se comprueba que la desviación típica de los residuos sea razonable y que parezcan ruido blanco; el intervalo de predicción se ensancha con el horizonte, como en el Tema 1.

7. SARIMA: cuando también hay estacionalidad

Idea simple

Un ARIMA mira a ayer y anteayer. Si las ventas de ropa dependen mucho de lo que se vendió hace un año (la Navidad se parece a la Navidad anterior), también hay que mirar a 12 meses atrás. Eso añade al modelo una segunda parte, copia de la primera, pero con retardos de s periodos.

DatosPeriodo sHay que mirar a…
Trimestrales4hace un año (4 trimestres)
Mensuales12hace un año (12 meses)
Diarios7hace una semana
Versión formal

SARIMA(p,d,q)(P,D,Q)s multiplica la parte normal por la parte estacional:

φ(L) Φ(Ls) (1−L)d (1−Ls)D Yt = c + θ(L) Θ(Ls) εt

Un ejemplo con s = 4:

(1 − φ1 L − φ2 L2)(1 − φ4 L4) Yt = c + (1 + θ4 L4 + θ8 L8)(1 + θ1 L) εt

Se identifica igual: los retardos estacionales (12, 24… en mensuales) se miran en la ACF y la PACF. Ejemplo del tema: ventas mensuales de ropa en EE. UU.

8. Python: de los datos a la predicción

Idea simple

Se separan los últimos datos, se ajusta el modelo con el resto, se predice y se compara con lo reservado. En el notebook AR se entrena con las primeras 89 observaciones y se dejan 6 para comparar; en el MA se entrena con las primeras 655.

from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox

adfuller(y)[1]                           # p-valor: ¿hay que diferenciar?
modelo = ARIMA(y, order=(p, d, q)).fit() # (1,0,0) = AR(1); (0,0,1) = MA(1)
print(modelo.summary())                  # coeficientes y AIC
acorr_ljungbox(modelo.resid, lags=[10])  # ¿residuos = ruido blanco?
modelo.forecast(steps=5)                 # predicción a 5 pasos

Identificar

ACF y PACF → candidatos (p, q).

Elegir

AIC más bajo; ante empate, el más simple.

Validar

Residuos sin autocorrelación (Ljung-Box).
