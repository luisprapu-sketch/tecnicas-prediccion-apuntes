Paso 2. ¿Es estacionaria?

Idea simple

Se pregunta si la serie «vuelve a su nivel» o se va por ahí. Tus apuntes lo resumen así: estacionaria = media constante y varianza constante. Para la media hay un test formal, el .

Test ADF
  • H0: los datos no son estacionarios en la media. H1: son estacionarios.
  • Si el < 0,05 se rechaza H0: es estacionaria.
  • Si el p-valor ≥ 0,05 no se rechaza: no es estacionaria, hay que transformar.

Cómo transformar

Para la media: Δ

Se diferencia. Si sigue sin ser estacionaria, se vuelve a diferenciar y se repite el ADF.

Para la varianza: log

Se aplica el logaritmo antes de diferenciar.

Para parar

Cuando el ADF da p < 0,05. No diferencies más de lo necesario.

Paso 3. ¿Hay autocorrelación?

Idea simple

Se mira si el dato de hoy se parece a los de días anteriores. Si no se parece a ninguno, la serie es impredecible con modelos lineales. Si se parece, hay patrón que aprovechar. En tus apuntes: datos incorrelados = ACF y PACF iguales a cero.

1. El gráfico

y . Si casi todas las barras quedan dentro de las , no hay autocorrelación.

2. El test

: H0 datos incorrelados; H1 datos correlados, que lleva a un modelo lineal.

3. La regla

p < 0,05: hay autocorrelación. p ≥ 0,05: no la hay.

from statsmodels.graphics.tsaplots import plot_acf, plot_pacf
from statsmodels.stats.diagnostic import acorr_ljungbox
plot_acf(y, lags=25); plot_pacf(y, lags=25, method="ols"); plt.show()
acorr_ljungbox(y, lags=[20], return_df=True)   # lb_stat y lb_pvalue

Ojo: lo normal es hacer este paso con la serie ya estacionaria (original o transformada). Con tendencia, la ACF baja muy despacio y el test siempre rechazará.

Paso 4. ¿Qué tipo de ruido blanco es?

Idea simple

Hay tres niveles, cada uno exige más que el anterior, como tres filtros seguidos. Si fallas el primero, no pasas a los siguientes.

WN · ruido blancomedia cero + incorrelado + varianza constante
· ruido blanco estrictoWN + independiente (se mira en los cuadrados)
· ruido blanco gaussianoSWN + normalidad

Se cumple GWN ⇒ SWN ⇒ WN, y al revés: si no es WN, tampoco es SWN ni GWN.

Paso 7. Diagnosticar los residuos

Idea simple

Si el modelo ha explicado todo lo explicable, lo que sobra (los residuos) debe ser ruido blanco: sin patrón. Se repiten sobre ellos las pruebas del paso 4. Si fallan, el modelo se puede mejorar.

Sobre los residuosSe espera
Gráfico, ACF y PACFTodo dentro de las bandas
Ljung-Boxp ≥ 0,05 (sin autocorrelación)
Ljung-Box sobre residuos²p ≥ 0,05 (varianza sin estructura)
Shapiro y cuantilesp ≥ 0,05; cuantiles 2,5 % y 97,5 % de los residuos estandarizados cerca de ±1,96
Ejemplo: el modelo (0,0,0) del PIB de España

Ljung-Box: 1661 (p = 0). Shapiro: p = 3,3·10⁻¹⁶. Ljung-Box de los cuadrados: 791,6 (p ≈ 10⁻¹⁵⁵). Los tres tests rechazan: los residuos están lejos de ser ruido blanco, así que ese modelo es insuficiente.

Paso 8. Predecir

Idea simple

Se pide al modelo la predicción de los próximos periodos con su margen de error. Para saber si acierta, se guardan al principio los últimos datos reales, se predicen y se comparan. En los notebooks se dejan fuera 6 observaciones (AR) o 5 (MA).

  1. Reservar los últimos datos: y = yy[0:89] (entrena) y yy[-6:] (compara).
  2. Predecir con intervalo: modelo.get_forecast(steps=6).
  3. Error = predicción − real. Se miden con , o .
  4. Intervalo al 95 %: predicción ± 1,96 × error estándar.
Ejemplo del notebook AR

Predicción 2,01 con error estándar 3,66: intervalo = 2,01 ± 1,96 × 3,66, es decir, de unos −5,16 a 9,18.

Aviso con modelos solo de media (0,0,0)

Si el modelo no explica nada, la predicción es la misma en todos los horizontes (en el PIB: 741.012 siempre) y el intervalo es enorme. Una predicción plana es señal de que el modelo no aporta información.

fc = modelo.get_forecast(steps=6)

se   = fc.se_mean                   # error estándar
ic   = fc.conf_int(alpha=0.05)      # intervalo al 95 %

9. Los casos prácticos, resueltos

Idea simple

Casi todas las series de los casos y trabajos caen en uno de cinco patrones. Reconocer el patrón dice qué hacer. Elige un bloque de casos para ver cada serie con su veredicto.

Ruido blanco

Sin autocorrelación ni tendencia. No hay modelo que ajustar.

Paseo aleatorio

No estacionaria; su diferencia es ruido blanco. Se diferencia y se acaba.

Correlada

Pico en ACF o PACF. Modelo lineal AR, MA o ARMA (con diferencias si hace falta).

Varianza cambiante

Es ruido blanco pero los cuadrados tienen patrón. Modelo no lineal.

Con estacionalidad

Picos en el periodo (4, 12, 7). Parte estacional SARIMA.

10. Plantilla completa de código

import pandas as pd, numpy as np, matplotlib.pyplot as plt
import scipy.stats as st
from statsmodels.tsa.stattools import adfuller
from statsmodels.tsa.arima.model import ARIMA
from statsmodels.stats.diagnostic import acorr_ljungbox
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

data = pd.read_csv("archivo.csv", sep=";", decimal=",")
y = data.iloc[:, 0]; plt.plot(y); plt.show()            # 1. mirar

print(adfuller(y, maxlag=10)[1])                         # 2. ADF
# y = np.log(y)   (varianza)    y = y.diff().dropna()   (media)

plot_acf(y, lags=25); plot_pacf(y, lags=25, method="ols")  # 3. ACF/PACF
print(acorr_ljungbox(y, lags=[20]))                      # Ljung-Box

print(st.ttest_1samp(y, 0).pvalue)                       # 4. tipo de ruido
print(acorr_ljungbox(y**2, lags=[20]))
print(st.shapiro(y).pvalue)

m = ARIMA(y, order=(1, 0, 0)).fit()                      # 6. ajustar
res = m.resid                                            # 7. diagnosticar
print(acorr_ljungbox(res, lags=[20]), st.shapiro(res))
fc = m.get_forecast(steps=5)                             # 8. predecir
print(fc.predicted_mean, fc.conf_int())

11. Checklist para entregar

Para cada serie

Responde con la serie original y con la transformada, siguiendo el formato del enunciado.

Intuición y tests

Primero lo que ves en el gráfico; después los tests. Si no coinciden, dilo.

Orden de las preguntas

Estacionaria → correlada → WN → SWN → GWN → ¿modelo lineal? → ¿modelo no lineal?

Con p-valores

Escribe siempre el p-valor y la decisión: «p = 0,58 ≥ 0,05, no se rechaza H0, no estacionaria».

Transformaciones

Δ para la media, log para la varianza. Indica cuáles aplicas y por qué.

Entrega

Nombre completo (trabajo individual) o grupo (trabajo de grupo) en el archivo, como pide el enunciado.
